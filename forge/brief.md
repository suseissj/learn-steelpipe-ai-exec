# brief — 철관 제조기업 임원을 위한 제조·경영 AI

## 핵심 질문

> **우리 철관 회사는 제조와 경영 중 어디부터 AI를 도입해야, 어떤 성과를 언제 확인할 수 있는가?**

| 항목 | 값 | 출처 |
|---|---|---|
| 주제 | 철강산업 철관(강관) 제조기업의 제조·경영 AI 활용 | 사용자 |
| 대상 | 철관 제조기업 임원 (의사결정권자 · 코딩 비전공) | 사용자 |
| 결과물 | 교재 3장 + 강의 덱 + 강의 스킬 | 사용자 |
| 원본 강의 | 내 업무 주제 (강의 저장소 Day 폴더 중 참고할 것은 미정) | 사용자 |
| 시간 | 1시간 30분 (블록 5~7개) | 사용자 |
| 말투 | 현장 용어 그대로 (열연코일·조관·ERW 용접·비파괴검사 등) + 경영 지표로 번역 | 대상에서 결정 |
| 수강생 환경 | Claude 데스크톱 앱 + 유료 계정 · GitHub 계정 | 가정 |
| 데이터 | 가상 데이터 (공개 가능한 수준으로 만든다) | 가정 |
| 공개 범위 | public (GitHub Pages) | 가정 |

## 결과물 구성

| 결과물 | 내용 |
|---|---|
| 교재 1장 — 제조 AI | 조관·용접 품질 검사, 설비 예지보전, 수율·불량 원인 분석 |
| 교재 2장 — 경영 AI | 수요·원자재(열연코일) 가격 예측, 수주·견적, 재고·생산계획 |
| 교재 3장 — 도입 로드맵 | 우선순위 판단(효과 × 실행 난이도), 파일럿 설계, 투자·성과 측정, 거버넌스 |
| 강의 덱 | report-navy-deck 스킬로 만드는 임원 보고형 네이비 덱 |
| 강의 스킬 | 수강생이 직접 따라 배우는 `learn-<주제>` 스킬 (course-forge) |

## 가정과 확인 필요
- 실제 회사 데이터 대신 가상 데이터를 쓸지
- 덱·사이트에 회사명·기관명을 넣을지 (기본은 넣지 않음)
