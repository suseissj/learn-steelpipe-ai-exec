## EXPLAIN

### 1. 오늘 쓰는 데이터 3종

| 파일 | 내용 | 쓰는 블록 |
|---|---|---|
| `production_lots.csv` | 가상 철관 공장의 생산 로트 — 일자, 품목(구경), 생산 본수, 용접 불량 본수, 조관기 진동(mm/s) | Block 1 제조 AI |
| `coil_price_margin.csv` | 2025-10 ~ 2026-09 월별 열연코일 가격(원/톤)과 품목 3개(구조관·배관용 강관·유정용 강관)의 판가·원가 구조 | Block 2 경영 AI |
| `ai_candidates.csv` | AI 도입 후보 과제 6개 — 연간 기대효과, 초기 투자, 데이터 준비도 | Block 3 도입 로드맵 |

| 용어 | 뜻 |
|---|---|
| 열연코일 | 철관의 원재료. 두루마리 형태의 강판으로, 풀어서 둥글게 말아 관을 만든다 |
| 조관 | 강판을 둥글게 성형해 관 모양으로 만드는 공정. 그 설비가 조관기 |
| ERW 용접 | 전기저항용접. 성형한 강판의 이음매를 전류로 붙인다. 철관 품질의 핵심 |
| 진동 (mm/s) | 조관기 롤·베어링 상태를 보는 센서 값. 서서히 오르면 마모 신호 |

데이터는 모두 **실습용 가상 데이터**다. 실제 회사 생산·원가 자료는 넣지 않는다.

### 2. 왜 임원이 직접 돌려 보나

| 기준 | 보고서만 받아 본다 | 직접 한 번 돌려 본다 |
|---|---|---|
| AI에 대한 감 | "AI가 알아서 한다"는 막연한 기대 또는 불신 | AI가 무엇을 잘하고 어디서 사람 판단이 필요한지 안다 |
| 투자 판단 | 담당 부서 설명에 의존 | 어떤 데이터가 있어야 효과가 나는지 질문할 수 있다 |
| 걸리는 시간 | 보고 한 번에 몇 주 | 프롬프트 한 줄에 몇 분 |

### 3. 오늘의 질문

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다. 출력 직전에 `{SKILL_DIR}`을 이 SKILL.md가 있는 실제 폴더 경로로 바꿔 보여 준다.

```
철관 AI 실습 준비를 해 줘.
1. 내 홈 폴더 아래 steelpipe-ai 폴더를 만들고, 그 안에 data 폴더와 out 폴더를 만든다.
2. {SKILL_DIR}/assets/lab/ 의 production_lots.csv, coil_price_margin.csv, ai_candidates.csv 를 steelpipe-ai/data/ 로 복사한다. 원본 파일은 고치지 않는다.
3. 파일마다 행 수, 열 이름, 단위(본, mm/s, 원/톤, 억원), 기간을 확인한다.
4. python3(또는 python), git, gh가 있는지 확인하고, gh auth status로 GitHub 로그인 여부를 확인한다. 로그인이 안 되어 있으면 브라우저 로그인용 일회용 코드만 보여 주고 나에게 비밀번호를 묻지 않는다.
5. 위 결과를 steelpipe-ai/env_check.txt 에 적고 세 줄로 요약해 준다.
```

사람이 직접 하는 일:
1. GitHub 로그인이 안 되어 있다면 화면에 나온 일회용 코드를 브라우저에 입력해 승인한다. (GitHub 계정이 없으면 Block 4는 강사 시연으로 대신한다.)
2. 끝나면 데스크톱 앱에서 **새 세션 → Local → `steelpipe-ai` 폴더 선택**으로 새 세션을 열고 `/learn-steelpipe-ai-exec`를 다시 불러 Block 1로 간다.
